# Avisos de terceros

AppHub se construye únicamente con el Android SDK y las clases del framework de Android. No incluye bibliotecas de terceros, AndroidX, Kotlin ni dependencias de red externas.

| Componente | Origen | Uso | Licencia |
|---|---|---|---|
| Android SDK / framework | Google | Activities, `PackageManager`, `DownloadManager`, `HttpURLConnection`, `SharedPreferences`, `org.json` | Android Open Source Project (Apache 2.0) |
| GitHub REST API | GitHub, Inc. | Búsqueda de repositorios, releases, README, contenidos del catálogo | Condiciones de servicio de GitHub |

Los logotipos, nombres y capturas de las apps listadas pertenecen a sus respectivos autores. AppHub muestra metadatos públicos de GitHub y enlaza a los repositorios originales; no se hace ninguna afirmación de propiedad sobre ellos.

La licencia del código de AppHub es MIT; consulta el archivo [LICENSE](LICENSE).
